# 🌐 نظام صائغ البرومبت ومستشار موديولات Ollama الذكي

برنامج متكامل ومستقل مطور بلغة **بايثون (Python)** يوفر واجهة رسومية تفاعلية حديثة تدعم اللغة العربية والاتجاه من اليمين إلى اليسار (RTL). يهدف البرنامج إلى دمج قوة نماذج الذكاء الاصطناعي المحلية (Ollama) مع أدوات فحص العتاد لإدارة وتوسيع البرومبتات بشكل احترافي وآمن تماماً.

---

## 💡 فكرة البرنامج الأساسية
تعتمد الفكرة على حل مشكلتين رئيسيتين يواجههما مهندسو البرومبت ومطورو الذكاء الاصطناعي:
1. **صعوبة كتابة البرومبتات الاحترافية (Prompt Expansion):** النماذج التوليدية (مثل Midjourney للمجال الرسومي أو أنظمة الكود) تتطلب صياغة إنجليزية سينمائية وهيكلية دقيقة. البرنامج يقوم باستقبال الفكرة البسيطة باللغة العربية، وترجمتها، ثم تطبيق تقنيات "الهندسة العكسية والتوسيع" لحقن تفاصيل متقدمة تلقائياً بناءً على نوع المخرج المستهدف (صور، نصوص، كود).
2. **عشوائية اختيار الموديل المناسب للجهاز:** تعتمد النماذج المحلية كلياً على حجم الذاكرة العشوائية الحرة (Free RAM). يقوم البرنامج بقراءة الرام الحية ومطابقتها حياً مع مستودعات Ollama الرسمية لتوجيه المستخدم للنسخة المثالية لجهازه لحمايته من التشنج أو الانهيار.

---

## 🛠️ كيف يعمل البرنامج بالضبط؟ (دورة حياة التشغيل)

عند إطلاق ملف الإقلاع الرئيسي، يمر البرنامج عبر 4 مراحل هندسية متسلسلة:

### المرحلة 1: الفحص الذكي والربط بالخلفية (Backend Initialization)
* يقوم البرنامج باختبار الاتصال مباشرة بالمنفذ الرقمي الصريح لـ Ollama المحلي وهو `http://127.0.0.1:11434`.
* **إذا وجد السيرفر نشطاً:** يتعرف عليه فوراً ويتحول للحالة الخضراء.
* **إذا وجده متوقفاً:** يقوم الكود بشكل مستقل بإطلاق دالة فرعية في الخلفية (`subprocess`) لتشغيل الأمر `ollama serve` صامتاً، مع تفعيل آلية انتظام ذكية لتفقد منفذ الشبكة لحين التأكد من الإقلاع التام.
* بمجرد استقرار السيرفر، يقرأ التطبيق ملفات الهارد ديسك محلياً لجمع قائمة بجميع الموديلات التي قام المستخدم بتحميلها مسبقاً، ثم يملأ بها **القمية المنسدلة (Combobox) العلوية** للاختيار الفوري.

### المرحلة 2: نظام التبويبات الهجين (Tabs/Notebook Layout)
تم تقسيم واجهة المستخدم رسومياً إلى تبويبين منفصلين لضمان تجربة مستخدم منظمة:
* **التبويب الأول (صانع وموسع البرومبت):** لوحة الإنتاج والتشغيل اليومي.
* **التبويب الثاني (مستشار وجلب الموديولات):** لوحة الإدارة التقنية ومطابقة العتاد.

### المرحلة 3: آلية عمل مستشار الموديولات (Tab 2)
* يقوم المستخدم بكتابة اسم العائلة البرمجية للموديل (مثل `qwen2.5` أو `llama3.2`).
* يتم استدعاء دالة الفحص الحية والتي تقوم أولاً بحساب الذاكرة العشوائية الحرة الحالية بدقة (Free RAM) عبر مكتبة `psutil`.
* يتواصل البرنامج مع الـ API الرسمي لمستودع أولاما لاستخراج النكهات والتفرعات المتاحة للنموذج (Tags).
* يتم تطبيق خوارزمية فرز صارمة تقسم النتائج إلى 3 فئات معروضة بشكل منظم:
  * ⚡ **أخف وأسرع:** نسخ صغيرة الحجم جداً وتعمل بسرعة فائقة بدقة متوسطة.
  * 🌟 **المظبوط والمثالي:** النسخة النموذجية المدربة التي تتسع بكفاءة داخل مساحة الرام الحرة الحالية مع ترك حد أمان لنظام ويندوز.
  * ⏳ **أعلى جودة لغوية:** نسخ أكبر بقليل من الرام المتاحة تمنح دقة أعلى ولكنها ستعمل ببطء.
* عند نقر المستخدم على زر **"اعتماد الموديل"**، يتم تمرير هذا الموديل برمجياً ليكون هو "المحرك النشط" للتوليد.

### المرحلة 4: معالجة النص وتوسيع البرومبت (Tab 1)
* يقوم المستخدم بكتابة فكرته باللغة العربية داخل صندوق نصوص يدعم اتجاه اليمين إلى اليسار (RTL).
* يختار المستخدم خيار التخصيص للمخرج (توليد صور، أو كتابة نصوص، أو برمجة كود).
* يتم إرسال المدخلات محلياً بنسبة 100% (لحفظ الخصوصية وبدون إنترنت) إلى الموديل النشط عبر نظام حقن محمي يحتوي على **System Prompt احترافي صارم**.
* **كيف تصاغ النتيجة؟** يقوم الـ System Prompt بإجبار الذكاء الاصطناعي على تقمص دور مهندس برومبتات خبير، فيقوم بترجمة الفكرة وصياغتها إنجليزياً مع تدعيمها بمصطلحات احترافية (مثل أبعاد الصورة، ونوع الإضاءة السينمائية للصور، أو معايير الكود النظيف للكود البرمجي)، ويخرج النتيجة داخل كتل برمجية واضحة جاهزة للنسخ بضغطة زر واحدة عبر زر النسخ المدمج.

## 📂 هيكلية ملفات المشروع المقسمة

يتم تنظيم المشروع هندسياً عبر ملفات منفصلة ومترابطة لمنع تداخل الأكواد وتسهيل التطوير:

* 📄 **`run.py`**: ملف الإقلاع الخفيف المسؤول عن بدء تشغيل النظام.
* 📄 **`main_gui.py`**: يحتوي على الهيكل الرسومي، وتنسيق التبويبات، وضبط الأيقونة والاتجاه العربي (RTL).
* 📄 **`gui_actions.py`**: عصب البرنامج؛ يحتوي على خيوط التشغيل المتوازية (`Threading`) لإبقاء الواجهة مرنة أثناء العمليات الحسابية الثقيلة، وإدارة أحداث الأزرار.
* 📄 **`ollama_engine.py`**: مسؤول عن إدارة اتصال الشبكة المحامي بالمنفذ الرقمي `127.0.0.1` وعمليات التوليد المحلي.
* 📄 **`ollama_scraper.py`**: مسؤول عن قراءة بيانات الرام الحية ومطابقتها تقنياً.
* 📄 **`prompt_db.py`**: مسؤول عن إدارة قاعدة بيانات وحفظ وتصفية البرومبتات (SQLite).
* 📄 **`AGENTS.md`**: الدليل المرجعي الفني الشامل لوكلاء ومساعدي الذكاء الاصطناعي (AI Agents).
* 🖼️ **`app_icon.ico`**: أيقونة النظام الرسمية المدمجة بالواجهة.
